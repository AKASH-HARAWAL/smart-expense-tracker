# Smart Expense Tracker 💰

A full-stack Expense Management System built using Spring Boot, Thymeleaf, MySQL, and Bootstrap.

---

## 🚀 Features

- User Login Authentication
- Add Expenses
- View Expenses
- Edit Expenses
- Delete Expenses
- Category Filtering
- Dashboard Analytics
- Expense Pie Chart
- PDF Report Download
- Responsive Bootstrap UI

---

## 🛠️ Technologies Used

- Java
- Spring Boot
- Thymeleaf
- MySQL
- Bootstrap
- Maven
- Chart.js
